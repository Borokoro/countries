# Countries

Welcome to the **Countries** project. It is a multi platform application that lists countries and their languages. Main purpose of this project is testing the usage of GraphQL API in flutter project.
**The program has only been tested on web, so please test it only on this platform.**
The program should also work on mobile systems, but this has not been tested.

## GraphQL
This application uses open GraphQL API that you can find under this [link](https://countries.trevorblades.com)

## Features

### Listing countries and their languages

When you launch the program, you will be prented with the list of counties and languages they use.

### Error management

The program has also built-in error managment so you can  be presented with error message instead of countries list if something goes wrong.
